# Snow Shot Community

基于 [Snow Shot](https://github.com/mg-chao/snow-shot) 的个人维护版，仅发布 Windows x64 完整版。保留本地截图、录屏、编辑、OCR 与用户自行配置的 PaddleOCR 服务，不依赖上游账户和付费服务。

在 [GitHub Releases](https://github.com/wxyu71/snow-shot/releases) 下载通过验收的预发布版本，按需选择在线或离线安装包。本项目不是上游官方发行版。
