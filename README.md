# Snow Shot Community

Personal, Windows x64-only distribution of [Snow Shot](https://github.com/mg-chao/snow-shot). The Community fork preserves local capture, recording, editing, OCR and direct user-configured PaddleOCR access without upstream accounts or paid-service dependencies.

Download the latest tested **prerelease** from [GitHub Releases](https://github.com/wxyu71/snow-shot/releases). Choose the online or offline installer. This is not the official upstream distribution.
